1. SYSTEM IDENTIFICATION
   Name: XoBrow (Executable aliases: "xobrow", "xb")
   Package: packages/xobrow
   Target Environment: Node.js (>= 18.0.0), ECMAScript Modules (ESM)
   Primary Target: Userscripts authored for the xokj Chromium CDP engine

2. PURPOSE AND DESIGN OBJECTIVES
   XoBrow is a dedicated static analysis and security auditing CLI tool. Its
   purpose is to inspect JavaScript and TypeScript userscripts prior to
   execution in browser environments possessing Chrome DevTools Protocol (CDP)
   bridge capabilities.

   Design constraints and operational principles:
   - Static Analysis Only: Scripts are analyzed solely via Abstract Syntax Tree
     (AST) parsing. No user code is executed, preventing arbitrary execution
     hazards during analysis.
   - Zero Code Mutation (Read-Only File Operations): XoBrow strictly analyzes
     and reports. It does not rewrite, format, or auto-fix user source code.
     Source files remain byte-for-byte identical before and after scanning.
   - Compiler-Grade Diagnostic Reporting: Violations are reported with exact
     1-indexed line and column coordinates, ASCII code frames containing
     gutter numbering, token pointer carets (^^^^), rule identifiers, and
     explicit remediation instructions.
   - Deterministic Exit Codes: The tool outputs predictable exit codes (0 for
     clean scripts, 1 for rule violations, 2 for operational/syntax errors)
     for seamless integration into CI/CD pipelines and automated pre-flight
     checks.

5. MINIMUM SYSTEM REQUIREMENTS
   - Runtime: Node.js version 18.0.0 or higher.
   - Operating System: Linux, macOS, or Windows (WSL / PowerShell / cmd).
   - Package Manager: npm (>= 8.0.0), pnpm, or yarn.
   - Memory Footprint: Standard AST parse allocations (< 64MB for typical
     userscript files under 50,000 lines).
